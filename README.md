# NASA Space Explorer

## Description

A React app that lets users explore NASA's daily astronomy media by date.

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- NASA APOD API

## Approach

Built with React using useState, useEffect, and fetch().
